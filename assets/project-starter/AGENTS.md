## Video Learning Workflow

This project uses the `video-learning-workflow` skill (open Agent Skills format).

Before planning, scripting, storyboarding, designing, producing, reviewing,
versioning, or preparing a release, load that skill and follow its routing,
operating rules, and publication boundary. In Codex, invoke it as
`$video-learning-workflow`; in other hosts, invoke it by name.

Skill folder (entry point `SKILL.md`): `__SKILL_ROOT__`

Start from `README.md` (status and folder map), `project-brief.md`,
`requirements.md`, and `decisions.md`. Read the recorded status before asking
for information already available, and confirm the current objective and input
versions before editing.

The workflow owns project consistency and coordination; specialist skills own
their own execution. Never publish (upload, make public, or schedule) without
the creator's explicit confirmation of that specific release.
